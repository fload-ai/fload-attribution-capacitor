# @fload-ai/attribution-capacitor

Fload install attribution for Capacitor apps (Apple Ads via AdServices, Google Play Install Referrer)

## Install

To use npm

```bash
npm install @fload-ai/attribution-capacitor
````

To use yarn

```bash
yarn add @fload-ai/attribution-capacitor
```

Sync native files

```bash
npx cap sync
```
